# Reuse task text from a recorded practice experience

In the practice workbook's literal history search, inspect a matching task and
choose **Replace selected lesson's next task with this exact task**. This explicit
replacement copies only the exact exercise text into the compatible selected
lesson in the teaching brief. Existing next-task text is replaced; no historical
or current observation is copied or edited.

The selected lesson must preserve the captured snapshot, retained examples and
example notice and match freshly loaded reviewed lessons. Missing, changed or
unavailable lessons cannot receive a historical task through this control.
Search changes, teaching edits, reordering and later browser requests invalidate
older callbacks. Unicode and whitespace are preserved without normalization.

Inspect or edit the resulting task in the teaching brief, then follow the
existing [next-round workflow](PRACTICE_ROUNDS.md). The old round is sealed and
new observations start blank. Workbook JSON retains captured rounds; an uncaptured
next-task draft belongs to the separately saved teaching brief. Cold resume still
requires preparing and rechecking that brief.

This is bounded operator-directed reuse supporting MOONBOOK-R02's reuse journey,
with historical evidence preserved for the ordinary R03 correction/review lane.
No authored requirement is marked closed, no learner improvement is inferred,
and no provider, deployment or release qualification is established.

After a reviewed version change, the separate [retest corrected guidance](RETEST_CORRECTED_GUIDANCE.md)
preview carries the exact task into an explicitly selected current version of
the same source family. Both scopes are shown before replacement and fresh
observations start blank. The exact-snapshot control above remains unchanged.
