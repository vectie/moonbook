# Find a recorded practice experience

In Bookkeeper → Reviewed lessons → Agent teaching brief → Agent practice
workbook, expand **Find a recorded practice experience** under Practice round
progression. Enter a case-sensitive literal phrase from a task, learner label,
lesson title, response, feedback or next-practice note.

Results cover all captured rounds, including tasks no longer in the current
round. Each result displays its original round and practice positions, learner,
task and all four observation fields. Choose **Prepare this experience for
correction** to open the existing correction editor for that exact round/task.
Continue with the normal version-history, rehearsal and review controls.

Search never edits the workbook or marks learning accepted. An empty query
shows no results; no semantic matching or effectiveness score is inferred.
The search phrase is temporary UI state; save the ordinary workbook JSON to
retain observations. Old guidance remains historical and must be rechecked
before applying a correction. No provider is called.
