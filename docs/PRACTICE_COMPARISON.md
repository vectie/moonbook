# Compare repeated practice

Open Bookkeeper → Reviewed lessons → Agent teaching brief → Agent practice
workbook → Practice round progression → **Compare the same practice task across
rounds**. Record a first response, then seal a round and start the next without
changing its task text to compare repeated practice. Save the editable workbook
before leaving the tab.

Each current task displays all rounds with the same source lesson family and
exact exercise text side by side. Source-family matching requires identical
lesson ID, outcome and assessment references, plus either the same legacy record
ID or canonical versioned record IDs documented in
[retest corrected guidance](RETEST_CORRECTED_GUIDANCE.md). Different version
records are compared without relabeling either historical capture.
The learner/session label, first response,
after-feedback response, authored feedback and next practice remain attributed
to their round. Missing responses say “Not recorded.” Different tasks are not
paired, including whitespace changes.

A changed lesson snapshot is clearly labelled; expand **Inspect captured
guidance and identity** to read each round's actual guidance and references.
This allows an operator to distinguish a repeated task from a repeated task
with different guidance. Each captured version and record ID is shown; matching
does not establish lineage or authenticate imported history.
Learner labels may differ and are shown, not inferred
as the same agent. No score, efficacy judgement or learning claim is generated.
Comparison only reads the workbook and never changes sealed rounds or accepts
a proposed correction. Use the ordinary correction controls for that workflow.
